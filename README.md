# pshist

Консольная утилита для Windows, которая собирает историю и следы работы PowerShell из разных источников в один отчёт и подсвечивает подозрительные команды. Написана на Rust, без внешних зависимостей.

## Что собирает

| Источник | Что даёт |
|---|---|
| `ConsoleHost_history.txt` (PSReadLine) всех профилей в `C:\Users`, PowerShell 5.1 и 7 | введённые команды (без времени, только дата изменения файла) |
| Журнал `Microsoft-Windows-PowerShell/Operational`, события 4104 и 4103 | тексты скриптов и команд, если включено логирование |
| Журнал `PowerShellCore/Operational`, события 4104 и 4103 | то же для PowerShell 7 |
| Журнал `Windows PowerShell`, события 400 и 403 | когда запускался и останавливался движок |
| Журнал `Security`, событие 4688 | запуск `powershell.exe` / `pwsh.exe` с командной строкой (нужен аудит процессов и права администратора) |
| Sysmon, событие 1 | командные строки процессов PowerShell (если Sysmon установлен) |
| Транскрипты `PowerShell_transcript.*.txt` и Prefetch | косвенные следы: что запускалось и когда |

Блоки скриптов, разбитые на части («1 из 10»), склеиваются обратно. Служебный шум автоматически сгенерированных модулей (cmdletization, например NetQoS) по умолчанию скрыт.

## Сборка

Нужен установленный Rust (https://rustup.rs). Файлы `main.rs`, `analyzer.rs` и `Cargo.toml` должны лежать в одной папке.

```
cargo build --release
```

Готовый файл: `target\release\pshist.exe`. Обычная сборка `cargo build` создаёт отладочную версию в `target\debug\pshist.exe`, она работает так же, но медленнее.

## Запуск

Запускайте из консоли, а не двойным щелчком: без аргументов утилита печатает справку и сразу завершается. Для чтения журнала Security и чужих профилей консоль нужно открыть от имени администратора.

```
pshist <С_КАКОГО_ВРЕМЕНИ> [опции]
```

Время можно задать так:

- относительно сейчас: `30m`, `2h`, `1d`, `1w`
- точной датой по местному времени: `"2026-11-14 20:00"`

Примеры:

```
pshist 2h                              # за последние 2 часа, вывод в консоль
pshist 1d --save                       # за сутки, плюс файл PowerShell_history.txt
pshist "2026-11-14 20:00" -o report.txt
pshist 1w --only-suspicious --save     # в полном списке только подозрительное
```

## Опции

| Опция | Описание |
|---|---|
| `-o`, `--out ФАЙЛ` | сохранить отчёт в указанный файл |
| `--save` | сохранить в `PowerShell_history.txt` в текущей папке консоли |
| `--all` | не скрывать служебный шум (cmdletization-модули) |
| `--only-suspicious`, `--susp` | в полном списке показывать только подозрительное |
| `--max-len N` | обрезать блоки скриптов до N символов (по умолчанию 4000) |
| `--hist-lines N` | сколько последних строк брать из файлов истории (по умолчанию 500) |
| `--tz-offset МИНУТЫ` | смещение местного времени от UTC (по умолчанию определяется само) |
| `-h`, `--help` | справка |

Файл с `--save` создаётся в текущей папке консоли, а не рядом с exe.

## Структура отчёта

1. Заголовок: период и часовой пояс.
2. Сводка: сколько подозрительных событий (высокий / средний / низкий уровень).
3. **Подозрительная активность (журналы событий):** что сработало, раскодированные Base64-вставки, найденные URL.
4. **События журналов** по времени. Подозрительные помечены `[!ВЫСОКИЙ]`, `[!СРЕДНИЙ]` или `[!НИЗКИЙ]`.
5. **Файлы истории PSReadLine.** Подозрительные строки помечены `[!]` и вынесены в отдельный раздел (время их выполнения неизвестно).
6. **Косвенные следы:** транскрипты и Prefetch.
7. **Замечания:** какие источники не удалось прочитать и почему.

## Анализатор подозрительных команд

Анализатор ищет признаки, на которые стоит посмотреть вручную:

- Base64: `-EncodedCommand` (включая сокращения `-e`, `-enc`) раскодируется из UTF-16LE и проверяется рекурсивно; длинные Base64-вставки в коде; `FromBase64String`; GZip внутри Base64
- скачивание: `Invoke-WebRequest` (`iwr`), `Invoke-RestMethod` (`irm`), `DownloadString`, `curl`, `wget`, `bitsadmin`, `certutil -urlcache`
- выполнение строк как кода: `Invoke-Expression` (`iex`); связка «скачал и выполнил» получает высший уровень
- скрытность и обход политик: `-WindowStyle Hidden`, `-ExecutionPolicy Bypass`, `-NoProfile`
- обход защиты: AMSI, отключение Defender, исключения Defender
- затирание следов: очистка журналов, отключение истории PSReadLine, подмена времени файлов, удаление теневых копий
- учётные данные и разведка: Mimikatz, LSASS, ntds.dit, SharpHound
- закрепление: планировщик, ключи Run, WMI-подписки
- инъекции в память, обратные оболочки, добавление пользователей в администраторы
- обфускация: сборка строк через `[char]`, склейка строк, обратные кавычки внутри слов
- URL на голый IP-адрес, пастебины, файлообменники, ngrok и подобные

Правила лежат списком в начале `analyzer.rs`; чтобы добавить или убрать правило, достаточно поправить одну строку.

## Ограничения

- Утилита не создаёт данные: если логирование блоков скриптов не было включено, а файл истории не вёлся, текст команд восстановить нельзя. Останутся только факты запуска (события 400/403, Prefetch).
- Анализатор работает по ключевым словам и не заменяет антивирус или EDR. Возможны ложные срабатывания (администраторы тоже пользуются `Invoke-WebRequest`) и пропуски (сложная обфускация).
- Журналы читаются через встроенный `wevtutil`, который при выводе в канал использует системную ANSI-кодировку. Символы вне этой кодировки (например, эмодзи) он заменяет на `?`, и восстановить их нельзя.
- Журнал `PowerShellCore/Operational` существует только если PowerShell 7 установлен и использовался; журнал Sysmon существует только при установленном Sysmon. Отсутствие этих журналов не ошибка.
- Утилита только читает данные и ничего не изменяет в системе, кроме создания файла отчёта.
